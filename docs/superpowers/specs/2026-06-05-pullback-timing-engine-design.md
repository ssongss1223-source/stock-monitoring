# 트랙 A — Robust 추세-눌림 타이밍 엔진 (Design)

작성: 2026-06-05 (세션 76)
상태: 설계 확정, 구현 계획 대기

---

## 1. 배경과 문제 정의

### 두 트랙 분리
- **트랙 B (1차 목표, 진행 중)**: Layer1~4 계층 ML 시스템. 단면(cross-sectional) "WHICH" — 오늘 어느 종목이 오를까를 ML이 랭킹.
- **트랙 A (본 문서)**: 시계열(time-series) "WHEN" — 하나의 자산에 대해 지금 들어갈/나올 타이밍. 트랙 B와 직교(orthogonal). 당분간 독립 개발, 성숙 후 결합(Layer4) 가능.

### 왜 이 설계인가 (브레인스토밍 결론)
1. **추세추종은 추세 차량에서만 작동.** TQQQ의 엣지는 "올랐으니까"가 아니라 구조적 논거 + 자기갱신 바스켓 + 하방방어. 개별 한국 종목 하나에는 이 셋이 없음 → 종목을 "이미 올랐다고" 고르는 건 hindsight bias.
2. **SMA 백테스터(v2)의 교훈**: 개별주 WF에서 sma_period가 윈도우마다 50~300을 널뜀 → 파라미터 비정상성(non-stationary). 종목별 파라미터 튜닝 = 과적합 함정.
3. **성숙한 강세장에선 돌파 매수가 늦음.** "강함을 사는" 돌파 → "약함을 사는" 눌림목 진입으로 전환이 국면에 더 적합.
4. **시계열 모멘텀은 가장 robust한 이상현상** (Moskowitz·Ooi·Pedersen 2012, AQR). 단, 지수 ≫ 바스켓 ≫ 단일종목 순으로 신호 대 잡음이 떨어짐 → **지수에서 먼저 검증** 후 무튜닝 전이.

### 성공의 정의 (지표 재설정)
- ❌ 버림: 강세장 vsBH(수익률로 buy&hold 압살) — 타이밍 전략은 강세장에서 구조적으로 짐.
- ✅ 채택: **전체 사이클(2005~2025) Calmar / MaxDD / Sharpe.** "상승의 대부분을 잡으면서 드로다운을 크게 줄임 = 더 높은 Calmar."

## 2. 목표와 성공 기준

**목표**: 한국시장의 성격(평균회귀·국면전환)에 robust한, **매수 *그리고* 청산 양방향 타이밍 엔진**을 만들고, 기초지수 20년으로 검증한 뒤 같은 규칙을 개별주에 **무튜닝 전이**시켰을 때 살아남는지 확인한다.

**성공 기준 (3중 robust 통과해야 "안다"고 인정)**:
1. **벤치마크 우위**: 기초지수에서 buy&hold 대비 Calmar 우위 (CAGR 대부분 유지 + MaxDD 유의하게 감소).
2. **대역 robust**: 단일 마법 값이 아니라 파라미터 대역(예: 추세 150~250, 눌림 30~70) 전반에서 작동.
3. **구간 robust**: 20년을 5년 단위로 쪼개도 대부분 구간에서 도움.
4. **무튜닝 전이 생존**: 지수에서 검증한 고정 규칙을 개별주 바스켓에 그대로 적용했을 때 종목 다수에서 살아남음. (종목별 튜닝을 해야만 되면 → 과적합, 기각.)

**비-목표 (명시적 제외)**:
- 정확한 저점/고점 포착 (극단 안 노림 — higher-low 매수, 추세붕괴 청산)
- ML, 단면 랭킹 (= 트랙 B 영역)
- 트랙 B와의 실제 결합 (성숙 후 별도)
- 레버리지 ETF 직접 검증 (역사 짧음·변동성 침식 → 응용 단계로 연기)
- 종목별 파라미터 튜닝 (변동성 정규화는 예외 허용)

## 3. 엔진 아키텍처

하나의 가격 시계열에 대해 매일 **롱(1) / 현금(0)** 을 출력하는 상태 머신.

```
1. 추세 게이트(Regime Gate) : 종가 > 상승중인 장기이평(200d) ?       → 추세 ON/OFF
2. 눌림 진입(Entry)         : 추세 ON + 가격이 중기이평(50d) 근접
                              또는 직전 고점 대비 되돌림 % 도달        → 매수(0→1)
3. 청산(Exit)               : 추세 OFF (장기이평 이탈 / 저점 갱신)     → 현금(1→0)
```

- **포지션은 이진 0/1.** 같은 추세-상태 엔진이 매수 질문과 청산 질문을 동시에 답함: 눌림 발생 시 추세 살아있으면 매수, 꺾였으면 그 눌림은 반전 시작 → 청산.
- **최소 변수로 시작**: 추세이평 + 눌림이평(또는 되돌림%)만. RSI·거래량·ATR은 처음엔 제외하고, 추가 시마다 "베이스라인보다 값을 더하나" 검증 통과해야만 채택.
- **베이스라인**: 장기이평 단순 교차(눌림 로직 없는 200d cross). 눌림 로직은 이 베이스라인을 이겨야 존재 정당.

### 정석 템플릿 기반 (발명 아님)
이 엔진은 새 파라미터를 데이터마이닝하는 게 아니라, 타 시장에서 이미 out-of-sample 증거가 있는 **표준 룰을 한국 지수에 재검증**하는 것이다. 이 자체가 과적합 방어책.
- **Meb Faber 200일선 타이밍 룰**(2007): 가격 > 10개월(≈200d) 이평이면 보유, 아니면 현금 — TQQQ식 타이밍의 교과서.
- **골든/데드 크로스**(50d × 200d): 가장 유명한 추세 필터.
- **200일선 위 눌림목 매수**(Connors/Alvarez 계열): "200d 위 종목이 50d로 눌리면 산다" — 문서화된 패턴.
- 따라서 50d/200d는 임의 하드코딩이 아니라 **표준 출발 기본값**이며, §6의 대역 스윕으로 "그 값 주변(장기 150~250, 중기 30~70)이 다 작동함"을 증명한 뒤 대역 중심값을 고정한다.

## 6. 검증 방법론 (핵심)

### 6.0 평가 지표 — 승률도 수익률도 아닌 위험조정수익
- **최적화·합격 판정 = Calmar (CAGR ÷ MaxDD).** Sharpe 보조.
- **승률(win rate)은 최적화 대상이 아니다 — 진단용 참고치.** 추세/눌림 전략은 본질적으로 승률이 낮음(~35~45%): 자주 작게 틀리고 가끔 크게 맞음. 승률을 올리려 튜닝하면 큰 추세를 일찍 잘라먹어 전략이 무너짐.
- 승률·profit factor·EV·거래수는 행동 이해용으로 *보고만* 하고 기준선에 넣지 않는다.

### 6.1 지수 검증 (P1~P2)
- 지표: 전체 사이클 Calmar / MaxDD / Sharpe / CAGR, 벤치마크 = 지수 buy&hold.
- **자기기만 방지 4체크** (SMA에서 배운 교훈):
  1. **파라미터 대역**: 추세이평·눌림 파라미터를 대역으로 스윕 → 한 값만 좋으면 탈락.
  2. **5년 구간 분할**: 2005-09/10-14/15-19/20-24/25- 등으로 쪼개 각 구간 기여 확인 → 한 국면 운이면 탈락.
  3. **거래비용 포함**: 수수료+슬리피지 반영.
  4. **베이스라인 비교**: 200d 단순 교차 대비 눌림 로직이 값을 더하나 → 아니면 눌림 제거.

### 6.2 무튜닝 전이 시험 (P3)
- 지수에서 통과한 **고정 규칙(대역 중심값 1세트)** 을 개별주 바스켓에 그대로 적용.
- 종목별 재최적화 **금지** (변동성 정규화 = ATR 스케일링만 예외 허용).
- 평가: 바스켓 전체 Calmar 분포, 살아남는 종목 비율. 다수 생존 → robust. 튜닝해야만 되면 → 기각·학습.

## 7. 단계 (Phase)

- **P0 — 지수 데이터 수집**: `market_index`에 1001/2001 20년치(2005~) 백필. 검증: 행수·기간·결측 확인.
- **P1 — 엔진 구현 + 단일 지수 1회 백테스트**: 신호 함수 + 러너. 코스피 지수에 기본 파라미터로 자산곡선·지표 산출.
- **P2 — Robustness 검증**: 파라미터 대역 스윕 + 5년 구간 분할 + 비용 + 베이스라인 비교. 코스피·코스닥 둘 다.
- **P3 — 무튜닝 전이 시험**: 고정 규칙을 개별주 바스켓(23종목 또는 확장)에 무튜닝 적용, Calmar 분포 평가.
- **(P4 — 보류)**: robust 확인 시 레버리지 적용/트랙 B 결합 검토. 본 spec 범위 밖.

각 단계는 다음 단계 진입 전 성공 기준 충족을 확인한다 (실패 시 기각·재설계).
